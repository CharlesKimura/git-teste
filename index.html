Comandos

git init - inicia o reporsitório

git status - mostra o estado dos arquivos

git add nome_arquivo ou . para todos arquivos. - adiciona os arquivos para o próximo commit

git commit -m "mensagem" - cria um commit com os arquivos adicionados

repositório conectado

git push - envia os commits para o repositório remoto

git log - mostra o histórico de commits

repositório não conectado

git remote add origin url_do_repositório - conecta o repositório local ao remoto

git remote -v - mostra os repositórios remotos conectados

git branch -M main - renomeia a branch atual

git push -u origin main - envia os commits da branch local para o repositório remoto
